Clinical background & approach progression
What is segmentation?
Per-pixel classification — assign a class label to every pixel in an image to delineate anatomically or functionally distinct regions. The model learns f(I(r); θ) that maps each location r to a label y(r) ∈ {0, 1, 2, …}. Binary case: foreground vs. background. Multi-class: simultaneous segmentation of multiple regions via softmax output.
Clinical applications
Brain parcellation (GM, WM, CSF), cardiac segmentation (LV/RV/myocardium → ejection fraction, wall thickness, mass), lung & heart from CXR, BraTS tumor subregions (enhancing tumor, necrosis, edema), acute ischemic stroke infarct core — critical within 24 hrs of onset.
Pharma R&D relevance
Tumor microenvironment characterization, spatial quantification of tissue compartments, treatment response scoring in clinical trials — directly connects to your AbbVie work and computational pathology & spatial transcriptomics goals.
Approach progression
Classical
Intensity thresholding
Fits Gaussians to histogram modes; simple but breaks when tissue intensity distributions overlap. Still used in MRI preprocessing pipelines.
Classical
Atlas-based segmentation
Register image to labeled atlas → propagate labels via inverse transform. Most common classical strategy. Fails with pathological anatomy, registration errors, or population differences.
DL v1
Patch-wise CNN
Classify center pixel of each overlapping patch. No architecture redesign; generates many training samples. Problem: one forward pass per pixel → extremely slow at inference.
DL v2
Fully convolutional network (FCNN)
Replace FC layers with conv layers → dense pixel-wise probability map. Needs upsampling to restore spatial resolution lost by pooling. Transpose conv introduces checkerboard artifacts — fix: bilinear upsample + regular conv.
DL v3
U-Net (dominant architecture)
Symmetric encoder–decoder with skip connections that copy-and-crop encoder feature maps directly into the decoder at each resolution level. Skip connections are the key innovation: they restore fine spatial detail lost during downsampling, enabling sharp, precise boundaries. IoU = 0.9203 at ISBI 2015 cell tracking challenge.
⚠ Checkerboard artifact: uneven kernel overlap in transpose convolution creates periodic intensity patterns. Fix: bilinear upsampling + regular conv decouples resolution increase from feature learning.
Architecture diagram
Why skip connections work
Downsampling builds semantic representations (what is in the image) but loses spatial detail. Skip connections inject the encoder's fine-grained spatial maps directly into the decoder, so it knows where those structures are — enabling sharp, clinically precise boundaries. Without them: blurry, spatially imprecise outputs.
Weighted cross-entropy loss
l = Σ_m w_m · Σ_c −y_mc · log(ŷ_mc)
Weight map w is computed from GT: boundary pixels and rare classes get higher weight. Directly addresses class imbalance and boundary sharpness — the same mechanism as weighted CE in your brain tumor classifier for glioma underdetection.
Why pixel accuracy fails
If background = 95% of pixels, predicting all-background scores 95% accuracy — but detects nothing. mIoU for the same prediction: 47.5%. Always use overlap-based metrics for segmentation.

The core problem with pixel-wise losses
What pixel-wise losses can't see
Cross-entropy and Dice only penalize per-pixel errors — they have no concept of global anatomical plausibility. A prediction can achieve good Dice while violating basic anatomical constraints (disconnected left ventricle, tumor extending outside the skull, left-right flipped organ). The model is rewarded for local pixel matches, not for understanding shape.
Anatomically constrained neural networks (ACNN)
Oktay et al., IEEE TMI 2018
Key idea: train a convolutional autoencoder on GT label maps to learn a compact latent shape manifold. At inference, penalize the predicted segmentation's latent code distance from valid shapes on that manifold.
L = L_x + λ₁·‖f(φ(x;θₛ);θ_f) − f(y;θ_f)‖₂² + λ₂‖θₛ‖₂²
  • L_x — standard pixel-wise classification loss
  • Middle term — shape representation error (distance in latent space from the GT shape manifold)
  • Last term — L2 weight regularization
Result: anatomically coherent outputs even with noisy or occluded inputs. The model is constrained to the manifold of plausible organ shapes.
GAN-based segmentation
Adversarial training
Generator = segmentation network. Discriminator = distinguishes predicted masks from real GT masks.

The adversarial loss forces the generator to produce segmentations that are globally indistinguishable from expert annotations — not just locally accurate pixel by pixel.
Pixel-wise loss = local referee
GAN discriminator = global referee
You need both for clinically valid outputs.
3D U-Net
Why 3D?
Biomedical structures are inherently volumetric. 2D slices lose inter-slice correlations and can produce artifacts where in-plane features mimic lesions. 3D networks capture full volumetric context and produce more globally consistent predictions.
3D U-Net mechanics
Same encoder–decoder as 2D U-Net but all convolutions are volumetric. Uses 2×2×2 pooling/upsampling; 5×5×5 convs at bottleneck. Each feature map is a 3D volume. Output: 2-channel softmax for binary segmentation. Çiçek et al., MICCAI 2016
2D vs 3D tradeoffs
DimensionWins onChallenges
2D More training samples (one per slice), lower memory, faster iteration Misses inter-slice correlations; in-plane artifacts; slice-level class imbalance
3D Better DSC, precision, fewer false positives (Zhang et al., IEEE TMI 2018); captures volumetric shape Far fewer training volumes; much higher memory; class imbalance even more critical; needs aggressive data augmentation (linear + nonlinear deformations)
Multi-contrast segmentation
Motivation & fusion strategies
Different MRI contrasts (T1, T2, FLAIR, DWI) highlight complementary anatomy. Combining them is especially useful for subtle lesions visible in only one modality.
StrategyHowProsCons
Data-level fusion Stack all contrasts as input channels to a single U-Net Simple; single model Early merging loses modality-specific feature structure
Feature-level fusion Separate encoder per contrast with cross-connections (Dolz et al., 2019) Modality-specific learning before merge; generally outperforms data-level More complex; higher parameter count

Feature-level fusion is directly analogous to integrating H&E morphology with spatial gene expression maps — you want modality-specific representations before fusion, not early concatenation.
